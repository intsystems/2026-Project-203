# Optional confidential AC/SPC comment

Decide whether there is a concrete reason to use this field. Options include (1) correcting a verifiable misunderstanding that affects the decision, (2) connecting evidence across several reviews, or (3) explaining a specific process concern supported by the record. The field can also be left unused.

For a scientific synthesis, identify the paper's contribution, name the reviewer's relevant point, give the evidence, state any proposed paper changes, and make a courteous request for acceptance if warranted. Use reviewer IDs and question numbers. Avoid score arithmetic, speculation about motives, or claiming that all concerns are resolved when evidence remains missing.

An agent must tailor this strategy to the actual reviews. Record the recommendation and alternatives here. Put comment text in `confidential_comment.json`; add clickable reviewer references to `workspace.json` under `confidential.references`. Internal links and strategy notes are excluded from the exported comment.

Verify the confidential field's permitted readers, deadline and limit. The default confidential character limit is unknown; do not assume the per-review limit applies. Follow the paper's configured external-link rule.
