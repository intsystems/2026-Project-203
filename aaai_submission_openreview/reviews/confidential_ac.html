How to run “Save to repo” and where it saves

Recommended: automatic local file saving.

  1. Open the aaai_submission_openreview folder in Windows File Explorer.
  2. Double-click start_workspace.cmd. It runs Python and opens http://127.0.0.1:8765/reviews/index.html.
  3. Open a review in that browser page and edit. Leave the Python window open. Edits save automatically after a short pause; Save to repo saves immediately.

If you opened the HTML directly: in desktop Edge or Chrome, click Save to repo, select aaai_submission_openreview (or its parent repository folder), and allow the browser to write there. Click it again after later edits. The folder selection lasts for this open tab.

Files written: confidential_comment.json stores answers, editable headings and notes; rebuttals/confidential_ac_comment.md stores the valid assembled response; response_history/ keeps previous versions.
