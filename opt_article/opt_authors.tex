%  OPT reviews double-blind, so the default build never reads this file:
%  opt2026.cls's [anon] option prints "author names withheld" and defines
%  \optauthor to swallow its argument.  It is read by

%      python make_opt.py --mode named     % names shown
%      python make_opt.py --mode final     % camera-ready
%
%  \Name, \Email and \addr are jmlr.cls's.  Braces around a surname keep a
%  multi-word one together, e.g. \Name{Jane {de Winter}}; a diacritic that
%  opens a forename is braced too, \Name{{\'E}louise Smith}.  Authors at one
%  address share a single \addr; separate addresses are divided by \AND.
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
